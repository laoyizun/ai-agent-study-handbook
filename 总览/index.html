1
功能 · 本地闭环
用 AI 帮你预习复习学科，把进度和闪卡整理到自己的 HTML 页面上，数据存于本地。
▶

核心命题

这一阶段解决"AI 帮学生做事，结果留在哪里"的问题。从"打开 AI 直接问"升级到"建工作空间 + 让 AI 输出变成可复用资产"。

关键能力

  • 搭建 workbuddy 工作空间，建学科对话
  • 让 AI 跨对话记住你（方式 A 复用开场白 / 方式 B 学习者档案）
  • 把 AI 输出整理成闪念本（学科元信息 / 卡点 / 好解释）
  • 用记忆卡片复习 + 三色标记（✓ △ ✗）
  • 把数据从浏览器搬到本地数据库

包含章节

  • L1 · 建工作空间 + 开第一个学科对话
  • L2 · 第二个学科对话 + 跨对话信息共享
  • L3 · 让 AI 输出变成可复用资产（闪念本）
  • L4 · 记忆卡片
  • L5 · 从浏览器到本地服务（SQLite）

交付物

· 1 个本地 HTML 复习页（带三色标记的闪卡）

· 1 个本地 SQLite 数据库（students + cards + reviews 三张表）

2
数据上云 · 跨设备
把阶段 1 的本地数据搬到云端，任何设备都能看到。
▶

核心命题

把 L5 搭的本地数据库搬到一个"任何设备、任何 AI 都能打开"的地方。

学生现状

已经能用 AI 生成闪念本和记忆卡片，已经有本地 SQLite 数据库。但数据只锁在家里电脑。

要解决的痛点

  • 周末去学校课室复习 → 数据库不在
  • 想让 AI 看"我最近哪类错最多" → AI 看不到
  • 爸妈问"你家娃复习得怎么样" → 你没法给他们看

关键能力

  • 理解"本机 vs 云端"的两种数据住址
  • 把 AI 之间的"接头暗号"（API key）讲成一个比喻，不出现密钥学术语
  • 写 prompt 让 AI 帮你迁数据
  • 抽样验证迁移没串（三色标记一致性）

包含章节

  • L6 · 把数据库搬上云端（本阶段唯一一章）

典型 AI 协作场景

① "让 AI 帮我建云端账号 + 3 张表 + 把本机数据搬上去"

② "让 AI 帮我处理 AI 报错（key 无效、字段不匹配）"

③ "让 AI 帮我验证迁移结果（抽样对比 5 张卡 + 三色标记）"

完成信号

  • 能在云端网站看到 3 张表
  • 抽样打开 3 张卡，内容和本机一字不差
  • 抽样 ✓ / △ / ✗ 各一条，颜色没串
→ 下一步：数据虽然搬上去了，AI 还是不会主动用 —— 这是阶段 3 的事。
3
AI 主动用 · 反向调用
AI 不再等你发问，而是主动读你的云端数据，告诉你"你最近该复习什么"。
▶

核心命题

把"学生主动问 AI"反过来，变成"AI 主动读学生的数据"。从被动工具变成主动助手。

学生现状

数据已经在云端，AI 能用 API key 读出来。但 AI 还在"被动回应"——你不问它不说。

要解决的痛点

  • 复习节奏靠你自己记得，AI 不提醒
  • 你不知道"我哪类错最多"，要手动翻卡片
  • 想生成周报要自己写
  • 学科 A 的 AI 看不到学科 B 的进度（信息孤岛）

关键能力（计划）

  • 让 AI 主动发问（基于数据反推）
  • 让 AI 基于 ✓△✗ 自动生成"明天该复习哪些"
  • 让 AI 在多个学科对话间共享同一份云端数据
  • 让 AI 写周报（基于本周复习历史）

包含章节（计划）

  • L7 · AI 主动读库 + 自动推荐复习（计划）
  • L8 · 跨学科对话 + 周报自动化（计划）

典型 AI 协作场景（计划）

① "AI 根据我最近的 ✓△✗，告诉我明天该复习哪 3 张卡"

② "AI 帮我写本周错题周报"

③ "我在学科 A 对话提问时，AI 能调用学科 B 的数据"

④ "AI 主动发'你 3 天前标 △ 的卡还没复习'提醒"

完成信号（计划）

  • 打开 AI 就能收到"今天该复习 X"的主动通知
  • AI 能告诉你"你这周数学的函数类错最多"
  • 一键生成上周复习周报
  • 跨学科对话能看到完整学习历史
→ 下一步：AI 主动用了，但还只能在浏览器看。下一步是把闪卡推到硬件（阶段 4）。
4
功能延展 · API + 硬件
加入更多 API 或硬件显示屏，做到"电子记忆卡片"。
▶

核心命题

把 AI 学习能力拓展到硬件和外部 API，闪卡不再只能"在浏览器翻牌"。

初步设想

  • 对接第三方 API（词典 / 题库 / 错题本 / 知识点图谱）
  • 接硬件（电子墨水屏 / 树莓派 / 手机推送 / 桌面小组件）
  • 让闪卡出现在任何有屏幕的地方
◇ 本阶段还在规划中。章节细节等阶段 3 完成后展开。
