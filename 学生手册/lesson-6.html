6

把数据库搬上云端

L5 你的数据库只在家里电脑。这一章让你把它搬到一个"任何时候都能打开"的地方 —— 同时理解 AI 替你做这件事时，用的是什么样的"接头暗号"。

一个真实的问题

你在 L5 让 AI 帮你搭了一个本地数据库，里面有你最近的卡片和三色标记。

但是 ——

  • 周末你在学校电脑打开复习页面 → 404，找不到
  • 你想让 AI 看「我最近哪类错最多」 → AI 说「我看不到你电脑里的数据库」
  • 你爸妈问「你家娃最近复习得怎么样」 → 你没法给他们看

为什么？因为那个数据库只在你家电脑的硬盘上。课室电脑、别的电脑、别的 AI，都碰不到它。

这一章解决：把数据搬到一个"任何地方都能打开"的地方。这个地方叫云端。

📌 类比补强：你 L4 在卡片上打的所有 ✓ △ ✗ 也会一起搬到云端。周末去课室复习时，颜色不变 —— 你之前"半掌握"的卡，云端看到还是"半掌握"。

📌 工作流（4 步）

1

概念 · 数据住址的两种选择

数据要"住"在一个地方。住哪，决定了谁能访问到它。

📖 本机 vs 云端 · 一张图讲清区别

左：数据锁在自家电脑的硬盘里。右：数据住在云端，4 个节点都能访问。

本机保险箱

  • 你家里的保险箱，只有你家的人能打开
  • 你换电脑 = 保险箱留在旧家，新家没有
  • AI 在别的电脑 = 看不到你保险箱里有什么
  • 别人想看 = 来你家

云端保险箱

  • 银行的保险箱，任何分行都能打开
  • 换电脑 = 换个分行开一下就行
  • AI 在任何电脑 = 都能读
  • 别人想看 = 你给账号 + 暗号，或者开一个临时权限

一句话总结：

本机 = 锁家里；云端 = 任何地方都能打开（但要账号密码）。

三个不够用的事 —— 换电脑 / AI 看不到 / 别人看不到 —— 三个都指向同一个解法：搬到云端。

2

概念 · "云端"对你来说是什么

云端听起来很玄。但对你来说，它就是一个有账号密码的网站。

📖 云端 = 网站 + 账号密码 + 表格编辑器

它对你来说长这样：

  • 一个网站 —— 你打开浏览器，输入网址，进去了
  • 账号密码 —— 你注册时设的，进门要输对
  • 一堆表格 —— 进网站后能看到，长得像 Excel
  • 点鼠标就能改 —— 你不需要写代码

关键澄清：

你依然不写代码。这跟 L5 一样 —— 你点鼠标、你看表格，你让 AI 替你处理脏活。

你和云端的区别只是：

  • 本地数据库 = 你电脑上的一个文件（看不见摸不着）
  • 云端 = 一个你能打开、能看到的网站
3

概念 · AI 之间的"接头暗号"

AI 帮你和云端打交道时，要报一串字符。这串字符就是API key。

📖 什么是 API key · 俱乐部暗号类比

AI 替你做事时，要先"亮身份"。暗号对了才能让云端开门。

类比：俱乐部暗号

你去一家老派俱乐部，进门要报"天王盖地虎"。只有对上暗号，服务员才让你进。API key 就是 AI 给云端报的暗号 —— 报对了，云端才让 AI 帮你读数据、写数据。

它长什么样？

AI 帮你处理时，截图里会出现类似这样的字符：

sb_publishable_JgjEFVnjeZPwzn9kO-2qCg_TpE6rIhB

看到 publishable 这个词是正常的 —— 意思是"可以公布在前端代码里"。这不是最高机密，但也不应该随便发。

为什么不能发到群里？

类比：你家门钥匙丢了 ≠ 别人能立刻进门，但风险变高了。

API key 泄露同理：拿到这个暗号的人能冒充你改你云端上的数据。比如把你"已掌握"的卡偷偷改成"未掌握"。

三条规矩：

  1. 截图发到群里之前，先打码这串字符
  2. 如果不小心发出去了，立刻在云端网站重置这个暗号
  3. 不要把暗号写进闪念本或工作空间文件（AI 会读到）

4

主课 · 让 AI 帮你搬

整个搬的过程不是你自己动手 —— 是你写 prompt，AI 干脏活。

整个搬的过程 = 你做一半（写 + 验证），AI 做一半（搬运）。

⚠️ 第一件事 · 报名字（必做，漏掉就全错）

在打开 AI 对话后，第一句就打这一行（把 your-name 替换成你自己的拼音）：

我是 your-name，本节课 L6 的学生

关键：your-name 填的是你名字后两个字的拼音。例如：

  • 皓霖 → haolin
  • 笑语 → xiaoyu
  • 周政亨 → zhengheng
  • 朱浩斌 → haobin
  • 吴旻骏 → minjun
  • 谭铭乐 → mingle（不是 mingyue！）

不报名字、或报错了，AI 写进数据库时 student_name 字段就会是错的或空的，所有数据全乱。漏掉这一步 = 后面的活白干。

📖 4.1 真实可用的 prompt · 复制就能用

这是「让你的 AI 直接连上本班云端数据库」的 prompt。前提：你已经在对话开头报过名字了（见上面那个橙色的"报名字"块）。

第一步 · 报名字（自己打这几个字）：

「我是 your-name，本节课 L6 的学生」

把 your-name 换成你的真实拼音（你老师给你的名字拼音）。这一步是 AI 写入数据库时必填的字段，不能省。

第二步 · 复制下面这段发给 AI：

你是本班的云端数据库协作助手，不是通用聊天 AI。

【角色】你懂 Supabase 公开 REST API，能帮学生读写数据库
【任务】
  1. 把我本机 SQLite 里的 3 张表（students / cards / reviews）搬到云端
  2. 我的本机数据文件路径：按你的环境（macOS 常见 ~/memory-cards.db 或学习笔记目录）
  3. 数据不丢，三色标记（✓△✗）不能串

【上下文】
  - 我是初中生，姓名（后两个字拼音）：your-name（← 把这里替换成你自己的拼音，比如 haolin / xiaoyu / zhengheng / haobin / minjun / mingle）
  - 我已经在对话开头打字告诉过 AI：「我是 your-name，本节课 L6 的学生」
  - 我已经在本地搭好 SQLite，字段名已经定好（students.name / cards.student_name / cards.subject / cards.question / cards.answer / reviews.mark / reviews.card_id）
  - 云端地址：https://rwdadlbtvjuoonnbbriy.supabase.co
  - 接头暗号（publishable key）：sb_publishable_JgjEFVnjeZPwzn9kO-2qCg_TpE6rIhB

【写库硬要求】
  - 写 cards / reviews 时，student_name 必须等于我刚才告诉你的那个拼音，不许写错
  - 不要替我改其他同学的 student_name（即使他们没在 devtools 里写死，你也别主动改）
  - 改 / 删任何记录前，先告诉我要改哪一条、为什么改，等我确认

【输出要求】
  - 第一步：先列出我本机 SQLite 的内容（有几张表、每张表几行、字段名），让我先确认是不是 3 张表
  - 第二步：再告诉我怎么连云端、用哪个 HTTP 路径插入数据
  - 第三步：插入完后，给我 5 个验证点（看下面 4.4）
  - 任何一步报错，把错误原文贴回来让我看

注意：这是 真实可用的 prompt，不是示例。把 your-name 换成你自己的拼音就能用。改的话自己写比复制更管用 —— 改的过程你会注意到"为什么要写这些字段"。

📖 4.2 拆解 prompt · 复用 L5 的四要素

L5 你学过 prompt 的四要素：角色 / 任务 / 上下文 / 输出。这一章不重复讲，直接引用 L5 的拆解（看 L5.4.2）。

这里只挑一点：上下文要写清楚"我的起点"和"我的目标"。

  • 起点 = 我已经在本地搭好 SQLite
  • 目标 = 把 3 张表搬到云端，数据不丢

AI 不知道你的起点和目标，就只能瞎猜。

📖 4.3 场景思考 · 你自己想写一个 prompt

不需要你现在就写出来。但想一想这个场景：

场景：你想让 AI 帮你只把 cards 这张表搬到云端，students 和 reviews 暂时不搬。

你要发给 AI 的 prompt 里，任务那一块大概怎么写？

动手之前，先在脑子里过一遍：

  • 角色：AI 是谁？「云端搭建助手」？
  • 任务：要 AI 做什么？（这一块要包含"只搬 cards"这个限定）
  • 上下文：你的起点是什么？你的目标是什么？
  • 输出：AI 该给你什么？「步骤 + 验证点」？

下次真要搬的时候，按这个结构自己写 —— 别复制，自己写。

📖 4.4 验证 · 怎么知道搬对了

AI 执行完后，你要能验证它做对了。AI 说"搬完了" ≠ 真搬完了。

5 个验证点：

  1. 看到 3 张表 —— 打开云端网站，能看到 students / cards / reviews
  2. 字段名一致 —— 字段名跟 L5 定义的一样（特别是 student_name、mark）
  3. 行数对得上 —— 云端的 cards 表有几行，跟你本机的行数对得上
  4. 内容抽样一致 —— 抽样 3 条卡片，看内容是不是和本机一字不差
  5. 三色标记没串 —— 抽样打开一条 ✓ 一条 △ 一条 ✗，看颜色是不是和本机一致（这条最重要 —— 颜色变了复习节奏就乱了）

为什么不验证 = 没学？

这是你和 AI 协作的核心循环：AI 做 → 你验证 → 不对就告诉 AI 让它改。AI 说"做完了"你就信，那不叫脚本，叫迷信。

📖 4.5 撞墙预案 · 如果 AI 报错

搬的过程不一定一次就成。最常见的几种报错：

报错原因怎么处理
key 无效暗号填错了 / 用过期的回到云端网站，重新复制一份新的
表已存在之前建过同名表让 AI 帮你"删旧建新"或"覆盖"
字段不匹配云端表的字段名跟本机不一样让 AI 改字段名，跟 L5 定义一致
网络超时云端连不上重试一次；还不行就在云端网站看下"服务状态"

任何一种报错，把错误原文贴给 AI，让 AI 自己排查。这是协作的核心。
