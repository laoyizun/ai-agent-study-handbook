📚 场景知识 · 场景 00

跟 AI 说话时，到底是谁在听你说话

模型 / 工具 / 上下文 + LLM 怎么"理解"语言

一个常见现象

你有没有经历过这种情况 ——

  • 你问 AI"昨天 2026 高考作文题是什么"，AI 答"我不知道"
  • 你问 AI"读我电脑里的 index.html"，AI 答"我看不到"
  • 你问 AI"用 Python 算 1+1"，AI 答"1+1=2"——但其实它没真的算
  • 你问 AI"小明借了小王一本书谁借出谁借入"，AI 答错

你以为这些是"AI 应该会"的事，它不会。除非给它工具。

知识 1 · 你以为的"AI"其实是 3 个东西

你看到的"AI 回答"，其实是 3 个东西一起工作 的结果：

图 1 · 你看到的"AI" = 模型 + 工具 + 上下文。任何一处没给，AI 都答不好。

关键认知：你看到的"AI" = 模型 + 工具 + 上下文。这 3 个东西 任何一个有问题，AI 都会答错。

知识 2 · 模型是什么

模型 = 一个根据上文"猜下一个字"的程序。

它：

  • 不知道真实世界发生的事（除非工具告诉它）
  • 没有长期记忆（每次新对话都"失忆"）
  • 看到的输入 = 你这次说的 + 上下文里有的
  • 输出的 = 一段"按概率挑的字"

类比：模型像一个 很会"接话茬"的人——你说"今天天气"，它能接"真不错"。但它不知道"今天"是哪天、你在哪、刚才发生了什么。

知识 3 · LLM 怎么"理解"语言 — token + 概率 + 温度

模型不是"看一个字，理解一个字"——它是 把字拆成"碎块"（token），按概率挑下一个 token。

① Token（碎块）

Token = AI 切的"碎块"——比字大、比词小。

语言举例Token 数
中文你好2 token
中文我看见了他5-6 token
英文hello1 token
英文conversation2-3 token

意义：AI 是按 token 计算"我看了多少字"——超出 token 限制它会"忘记"前面的内容（上下文窗口）。

② 概率分布（怎么"猜"下一个 token）

模型内部有一张 概率表——前文是 X，下一个 token 是 A 概率 80%、B 概率 15%、C 概率 5%。

它不是"猜"，是 "按概率挑"。所以：

  • AI 不会一字不差复述——但会"复述大意"
  • AI 会"撒小谎"——它选概率最高的，但概率最高 未必是真
图 2 · AI 不是"理解"句子，是给每个可能的意思排概率，选概率最高的那个。
图 3 · 字面"败"和实际"胜"意思相反，但 AI 选的是概率高的语义理解（92%）。

③ 温度（temperature）

温度 = AI 的 "音量旋钮"，控制 AI 选 token 的"冒险程度"。

温度AI 行为效果
≈ 0永远选概率最高的 token答得稳但单调
≈ 0.7（默认）大部分选高的，偶尔选低的平衡
= 1.0经常选低概率的答得有创意但可能跑偏
> 1.0几乎随机胡言乱语

温度调高会出现：

  • 同一问题不同回答
  • "幻觉"（自信地说错）
  • 写作更有创造性

所以 AI 为什么"撒小谎"：AI 选概率最高的，但概率最高 ≠ 真的。温度越高，AI 越敢选低概率的答案，幻觉越多。

知识 4 · 模型默认不能做什么

在 不加工具 的情况下，模型做不了这些事：

模型不能做的原因
看实时信息（今天天气 / 高考题）它没联网
看你的文件（index.html）它读不到你电脑
跨对话记住你每次新对话都"失忆"
执行真实操作（发邮件 / 改文件）它只是输出文字
算数学（准确）它"猜"字不是计算器
看图（基础模型）需要带视觉的模型

知识 5 · 怎么让模型"变能"——加工具

工具 = 模型能调用的 外部能力。工具补的是"模型不能做什么"。

工具类型解决"模型不能 X"
联网搜索不知道实时信息
读文件 / 读 PDF看不到你电脑里的文件
执行代码不能算 / 不能画
画图生图不能生成图像
调 API不能查数据库 / 发邮件
看图视觉不能看图片（基础模型不能）

关键认知：你让 AI"读这个文件"——AI 不会自己读，是 工具去读，再把结果告诉 AI，AI 才"看到"内容。

知识 6 · 上下文是什么

上下文 = 你在当前对话里 已经说过的所有内容，包括：

  • 你的 prompt
  • AI 的回答
  • 你上传的文件
  • 工具的返回结果

上下文 决定 AI 怎么接话——上下文长，AI 接得准。

上下文有限度：太长了 AI 会"忘记"前面的内容（超出 token 限制）。

类比：上下文 = AI 的"短期记忆"——它记得你刚才说了什么，但记不得太远的事。

知识 7 · AI 答错时，3 步诊断

AI 答错，不是"AI 不行"——是 模型 / 工具 / 上下文 某一个没给对。用 3 步诊断：

AI 答错的样子看怎么修
答得"水" / 不准 / 太简单 模型 换更强的模型（Pro / Sonnet / o1）
答"看不到" / "找不到" 工具 确认你让 AI 用了对应工具（"读这个文件"）
答"不知道" / "我猜" / 胡说 上下文 检查 prompt 给的信息够不够

实战流程：

  1. 先看是哪种错（答得水 / 看不到 / 不知道）
  2. 对到 3 元模型（看模型 / 看工具 / 看上下文）
  3. 补那一项，再问一次

实战任务 · 用 3 步诊断解决你的一次"AI 答错"

任务：挑你最近一次"AI 答错"的经历，按 3 步诊断是 模型 / 工具 / 上下文 哪个问题。

📖 场景 1 · AI 答得"水"

症状：你让 AI 解释"函数的概念"，AI 答得很水，比教材还差。

诊断：答得水 = 模型问题。

修法：换更强的模型（满血版 = Pro / Max / Opus / o1）。

📖 场景 2 · AI 答"看不到"

症状：你说"读我电脑里的 index.html"，AI 答"我看不到你电脑"。

诊断：看不到 = 工具问题。

修法：用 workbuddy 的"读文件"工具，或者把文件内容复制到 prompt 里。

📖 场景 3 · AI 答"不知道" / 胡说

症状：你问"2026 高考语文作文题"，AI 答"我不知道 2026 的"或编一个假题。

诊断：不知道 = 上下文问题（你 prompt 没给）+ 工具问题（没联网）。

修法：用联网搜索工具 + 在 prompt 里说"先搜索 2026 年高考作文题再答"。
